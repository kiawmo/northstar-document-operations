# Changelog

## 1.0.0

Initial standalone open-source release: authenticated ingestion, isolated PDF/OCR parsing, validated extraction, operator review, SQL queue leases and fencing, durable idempotency receipts, acknowledgment outbox, optional IMAP/SMTP, Redis hints and the complete LLM gateway.

Includes independent Compose configuration, generated local secrets, hash-locked dependencies, reproducible tests, deployment and recovery documentation. No hosted service, commercial accounting connector or externally verified mailbox account is bundled.
